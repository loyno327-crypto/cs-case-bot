# CS Case Bot — Telegram мини-игра (WebApp)

Мини-игра в стилистике CS: кликер, прокачка уровня, кейсы со скинами, апгрейд предметов,
контракты, сражения и ежедневный бонус. Приложение открывается как Telegram **Mini App (WebApp)**.

**Стек:** aiogram 3 (бот) + FastAPI (API и раздача WebApp) + SQLite (SQLAlchemy async).

---

## Структура проекта

```
├── app/
│   ├── config.py        # настройки из .env
│   ├── database.py      # подключение к БД (async SQLAlchemy)

│   └── seed.py          # наполнение БД демо-скинами и кейсами
├── static/
│   ├── index.html       # оболочка WebApp
│   ├── css/style.css    # дизайн в стилистике CS (зелёно-белая гамма)
│   ├── js/              # api.js, ui.js, screens.js, app.js
│   └── img/             # сгенерированные картинки скинов, кейсов, аватар

├── run.py               # единая точка запуска (сервер + бот)
├── requirements.txt
└── .env.example
```

## Быстрый старт (локально, тест в браузере)

Не требует токена бота — работает демо-игрок (`DEBUG=True`).

```bash
# 1. Создать окружение и установить зависимости
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Наполнить базу демо-данными (скины + кейсы)
python run.py seed

# 3. Запустить только сервер (WebApp + API)
python run.py server
```

Открой в браузере **http://localhost:8000** — увидишь игру с тестовым игроком GreenLegend.

> Использовался `uv`? Тогда команды: `uv venv && uv pip install -r requirements.txt`,
> а запуск через `uv run python run.py server`.

## Полный запуск с ботом в Telegram

Telegram открывает Mini App только по **HTTPS**. Локальный сервер отдаёт HTTP,
поэтому нужен публичный HTTPS-адрес — проще всего через туннель.

### 1. Создай бота и получи токен

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → получи `BOT_TOKEN`.
2. (Опционально) `/setmenubutton` — можно назначить кнопку меню на WebApp.

### 2. Подними HTTPS-туннель на порт 8000

С помощью ngrok:

```bash
ngrok http 8000
# скопируй адрес вида https://xxxx.ngrok-free.app
```

Или cloudflared:

```bash
cloudflared tunnel --url http://localhost:8000
```

### 3. Заполни `.env`

```bash
cp .env.example .env
```

```env
BOT_TOKEN=123456:ABC-твой-токен
WEBAPP_URL=https://xxxx.ngrok-free.app   # адрес туннеля
DEBUG=False                              # на проде проверяем подпись Telegram
```

> Важно: `WEBAPP_URL` должен указывать на **корень** сервера (там лежит `index.html`).

### 4. Запусти всё вместе

```bash
python run.py            # поднимет FastAPI-сервер и бота одновременно
```

В Telegram открой своего бота → `/start` → нажми **«Открыть игру»**.

## Игровые механики

- **Кликер** — клик по кнопке CS даёт монеты; доход растёт от прокачки.
- **Улучшения** — доход за клик, доход в секунду (пассивный), автоклик.
- **Пассивный доход** — начисляется даже пока игрок офлайн (при следующем заходе).
- **Уровни / XP** — за клики и действия; прогресс уровня в шапке и профиле.
- **Кейсы** — платные и бесплатный; случайный дроп скина по весам редкости.
- **Инвентарь** — выпавшие скины; можно продать за монеты.
- **Апгрейд предметов** — шанс улучшить скин до более дорогого (риск потери).
- **Контракты** — обмен нескольких скинов на один более ценный.
- **Сражения** — ставка монет с шансом на выигрыш.
- **Ежедневный бонус** — награда раз в 24 часа.

## Настройка и баланс

- Формулы дохода, стоимости улучшений и XP — в `app/game.py`.
- Список скинов, кейсов и веса выпадения — в `app/seed.py`
  (после изменений удали `game.db` и снова запусти `python run.py seed`).
- Внешний вид — `static/css/style.css` и рендеринг экранов в `static/js/screens.js`.

## Частые вопросы

- **Открываю WebApp в Telegram — белый экран.** Проверь, что `WEBAPP_URL` — это HTTPS-адрес
  работающего туннеля и что сервер запущен.
- **401 Invalid Telegram init data.** На проде `DEBUG=False` требует валидную подпись:
  открывай игру через кнопку в боте, а не по прямой ссылке в обычном браузере.
- **Хочу тестировать в браузере.** Поставь `DEBUG=True` — тогда работает демо-игрок.
- **Сбросить прогресс.** Удали файл `game.db` и запусти `python run.py seed`.
